# B1N-345 — 48-hour ETH/USDC Binary wheel backtest

This research package simulates the vault as if Binary had existed throughout the
historical window. Deribit supplies historical ETH/USD spot and ETH DVOL only.
Option premiums are **not Deribit fills**: every premium is generated by the
production Market Maker functions in `src/pricer.py`:

1. choose the strike nearest the configured target delta;
2. apply Binary's volatility skew;
3. calculate Black-Scholes value;
4. apply Binary's dynamic spread for gamma and utilization;
5. treat the resulting USD-per-ETH bid as the premium paid to the vault.

## Binary normalization

- Underlying: ETH.
- Accounting/collateral: USDC, treated as USD at par.
- Premium: linear USD/USDC per ETH contract.
- CSP payoff at expiry: `max(strike - settlement, 0) * ETH amount`.
- Covered-call payoff: `max(settlement - strike, 0) * ETH amount`.
- A put assignment spends `strike * ETH amount` USDC and creates a distinct ETH
  lot at the gross strike basis.
- Every call uses a strict strike above that individual lot's gross basis plus
  `X`. Weighted gross/net bases are sensitivity constraints only and can never
  relax the individual-lot protection.

This is a counterfactual Binary simulation. Deribit trades must never be
described as historical Binary fills.

## Coverage gate

The gate is fixed in `config.json`, before returns are inspected:

- causal spot/IV/settlement coverage must be at least 95% in every window;
- missing rows must be at most 5%;
- spot observations may be at most 8 hours old;
- IV observations may be at most 6 hours old.

The full run refuses to start unless `coverage_probe.json` passes. Output keeps
`observed`, `modeled`, and `missing` separate. Historical spot/IV inputs are
observed; all hypothetical Binary premiums are modeled.

## Reproduce

From the repository root, using Python 3.13 and `uv`:

```bash
uv run python scripts/run_b1n_345_backtest.py extract \
  --cutoff 2026-07-15T08:00:00+00:00
uv run python scripts/run_b1n_345_backtest.py probe
uv run python scripts/run_b1n_345_backtest.py run
```

The extractor writes raw API responses, a normalized market snapshot, and a
SHA-256 manifest under `data/`. The run writes machine-readable CSV/JSONL,
coverage details, rankings, benchmarks, and sensitivities under `results/`.

All windows share the same cutoff, $100,000 initial capital, data methodology,
and 48-hour cadence. “One/three/six months” are fixed trailing 30/90/180-day
research windows.
